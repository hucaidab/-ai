# 手机 MES 生产制造流程 - DSL 建模（对话实测）
标题: 手机 MES 生产制造流程
部门: 生产计划 (计划员)
部门: 仓储部 (仓管员)
部门: SMT 车间 (SMT 操作员)
部门: 组装车间 (组装工)
部门: 测试部 (测试员)
部门: 品质部 (质检员)
部门: 包装部 (包装员)

开始: 计划员.下达生产工单（MES 建单）
步骤: 计划员.生产排程
步骤: 仓管员.按工单备料
判断: 仓管员.备料齐全?
步骤: SMT 操作员.领料上料
步骤: SMT 操作员.SMT 贴片首件
判断: SMT 操作员.首件合格?
步骤: SMT 操作员.批量贴片与回流焊
步骤: 组装工.整机组装
步骤: 测试员.功能测试
判断: 测试员.测试合格?
步骤: 测试员.老化与可靠性测试
步骤: 质检员.成品检验
判断: 质检员.检验合格?
步骤: 包装员.包装
步骤: 仓管员.成品入库 MES 过账
结束: 计划员.生产完成

流程: 下达生产工单（MES 建单） → 生产排程
流程: 生产排程 → 按工单备料
流程: 按工单备料 → 备料齐全? --齐全--> 领料上料
流程: 备料齐全? --缺料·补料--> 按工单备料 (逆向)
流程: 领料上料 → SMT 贴片首件
流程: SMT 贴片首件 → 首件合格? --合格--> 批量贴片与回流焊
流程: 首件合格? --不合格·调参重试--> SMT 贴片首件 (逆向)
流程: 批量贴片与回流焊 → 整机组装
流程: 整机组装 → 功能测试
流程: 功能测试 → 测试合格? --合格--> 老化与可靠性测试
流程: 测试合格? --不良·返工--> 整机组装 (逆向)
流程: 老化与可靠性测试 → 成品检验
流程: 成品检验 → 检验合格? --合格--> 包装
流程: 检验合格? --不合格·返工重检--> 成品检验 (逆向)
流程: 包装 → 成品入库 MES 过账
流程: 成品入库 MES 过账 → 生产完成
