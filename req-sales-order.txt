# 销售订单流程 - 自然语言建模示例
标题: 销售订单处理流程
部门: 销售部 (销售员, 销售经理)
部门: 仓储部 (仓管员)
部门: 财务部 (应收会计, 出纳)
部门: 客户 (客户)

开始: 客户.发起订单需求
步骤: 销售员.创建销售订单 SO
判断: 销售经理.金额超限?
步骤: 销售员.确认订单
步骤: 客户.确认订单
步骤: 仓管员.拣货出库
步骤: 仓管员.物流发货
步骤: 应收会计.开具发票
步骤: 客户.收货并验收
步骤: 应收会计.对账
步骤: 客户.支付货款
步骤: 出纳.收款核销
结束: 出纳.订单完成

流程: 发起订单需求 → 创建销售订单 SO
流程: 创建销售订单 SO → 金额超限? --通过--> 确认订单
流程: 金额超限? --驳回--> 创建销售订单 SO (逆向)
流程: 确认订单 → 确认订单
流程: 确认订单 → 拣货出库
流程: 拣货出库 → 物流发货
流程: 物流发货 → 收货并验收
流程: 收货并验收 → 开具发票
流程: 开具发票 → 对账
流程: 对账 → 支付货款
流程: 支付货款 → 收款核销
流程: 收款核销 → 订单完成
